# Contributing

Thanks for helping improve ContextBridge.

1. Keep the MVP local-first and dependency-free unless a proposal explains the need for a dependency.
2. Never add real credentials, customer data, private repositories, or production logs to tests or examples.
3. Update the skill/commands and `tests/TEST_PLAN.md` when behavior changes.
4. Run `python3 -m unittest discover -s tests -v` before opening a pull request.
5. Describe what changed, why it helps account handoff, and how it was tested.

Please keep claims about automatic synchronization, account memory, and supported platforms accurate. ContextBridge stores explicit files; it does not migrate private chats.
